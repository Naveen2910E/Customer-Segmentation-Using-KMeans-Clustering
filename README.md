# Customer-Segmentation-Using-KMeans-Clustering

Retail Customer Segmentation Using KMeans Clustering
This project demonstrates an end-to-end application of unsupervised machine learning for customer segmentation in the retail sector. The approach leverages a dataset containing over 2,200 customer records and 30 features—including demographic variables (age, income, education, marital status), transactional data (purchase frequency, spend across categories), and engagement metrics—to uncover data-driven customer segments.

Methodology
Data Cleaning & Preparation: Handled missing values, addressed duplicates, and performed outlier detection to ensure high-quality input data. Features were engineered to aggregate spending, calculate customer tenure, and combine household variables for richer insights.

Feature Selection & Scaling: Selected key variables representing demographic, behavioral, and financial profiles. Standardized all numerical features to facilitate cluster analysis and reduce bias from scale differences.

Clustering Algorithm: Applied KMeans clustering. Used the Elbow Method to identify the optimal number of clusters, and validated with visualization and cluster interpretability tests.

Dimensionality Reduction & Visualization: Used PCA to reduce complexity and visualize clusters, enabling easier interpretation of group characteristics.

Cluster Profiling: Analyzed average values and distributions within each segment to identify actionable customer profiles for marketing, targeting, and personalization.

Business Impact
Segmenting customers allows retailers to:

Develop personalized marketing strategies based on distinct behavior and demographic patterns.

Optimize business decisions, such as campaign targeting, retention efforts, and resource allocation, by focusing on high-value segments.

Enhance customer satisfaction and loyalty through data-driven insights and tailored experiences.
